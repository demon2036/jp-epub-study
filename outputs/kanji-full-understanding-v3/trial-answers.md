# 答案：把选择的理由也说出来

先完成题目，再对照这里的解释。日语例句提供一种自然说法；学习时要认清的是场景中的关系。

<h2 id="answer-4e0b">下｜刻度、路线、原来的位置</h2>

1. **音量を下げる（おんりょうをさげる）**。音量放在高低尺度上，你调节它，使它降低，所以选下げる。下す这一章里常接判决的作出；下ろす则适合卸下架子上的行李。三个“下”有不同的场景入口。
2. 巴士是**离开的场所**。バスを降りる跟着人从巴士里下来，を在这里标出离开的范围。与之比较，荷物を下ろす中的荷物是被移下来的对象。
3. **kuda-r-u／kuda-s-u**：kuda是两词共有的下行、下达这一核心；r一支描写变化发生，s一支加入促成、作出这一作用；u是这两个五段动词辞书形的结尾。戻る／戻す也能这样记：回到原处／使东西回到原处，也就是放回。上げる切成**age-ru**，最后的る是一段动词的辞书形结尾；认的是完整的age-，它表示举高、提高，是他动词。
4. 下書き（したがき）：正式稿之前垫一层底稿；川下（かわしも）：顺着河流到后段；先生の下で（せんせいのもとで）：在老师的指导、支持下；地下（ちか）：地面这条线以下；下校（げこう）：和登校成对，放学离校；下手（へた）：技能表现不熟练，与上手配对。**教えてください**从教えてくださる接住“对方给予我指导”，再变成请求这项帮助。

<h2 id="answer-4e0a">上｜水平升高与把水平提高</h2>

1. **成績が上がった（せいせきがあがった）**，成绩提高了。想表达自己的目标，可以说**成績を上げたい（せいせきをあげたい）**，想提高成绩。一个报告水平的变化，一个把提高这个水平作为要做的事。
2. 上がる保留的是**agar-**，接i和ます，r＋i呈现り；上げる保留的是**age-**，直接接ます。它们看起来都以る结尾，完整词干却不一样。
3. 書き是書く连接下一动词的形式，后面的上げる在这个复合词里表示把写作推进到完成。**書き＋上げる**先组成“写完”，然后整个词说过去，成为書き上げた。
4. 机の上（つくえのうえ）找相对于桌面的上方；上着（うわぎ）找覆盖在外面的一层；川上（かわかみ）沿河找源头一侧。上司（じょうし）在组织层级之上；上人（しょうにん）是高僧的敬称；上手（じょうず）表示技术熟练。把事项提到讨论桌面，可用**議題に上す／上せる（ぎだいにのぼす／のぼせる）**；两词都表达提上来，活用分别是五段与一段。

<h2 id="answer-51fa">出｜出现、拿出、动作开始显现</h2>

1. 感冒失声，**声が出ない**：关注声音出不来。提醒保持安静，可说**声を出さないで（こえをださないで）**：请别发出声音。前者报告发声状况，后者要求对方别做发声的动作。
2. **泣き＋出す**把出す用于整个动作的开始：哭泣从没有发生到开始显现。变化落在孩子开始哭这件事上，句子依旧是子どもが泣き出した。
3. **見＋いだす**与**思い＋だす**。見いだす的后项保留较长的いだす；思い出す的い属于思い。先认出组成它的两个词，再切分声音，才能把新词接到已有记忆上。
4. 出場（しゅつじょう）是出场、参赛；出席（しゅっせき）是到场参加会议等；出納（すいとう）是钱款、物品的收进与付出。出席在字音接合里让しゅつ出现为しゅっ，**しゅ・っ・せ・き**中间的っ占一拍。出納整词记すいとう，可借钱像水一样流入、流出的画面钩住すい。

<h2 id="answer-5165">入｜沿着对象进入，或把对象放入</h2>

1. いる的连用形是いり，进入“口”就是入口（いりぐち）；**ir-u／ir-e-ru**把进入与放入连在一起。はいる在较长的“爬着进入”表达中保留了いる这一支。一组关系能同时提醒三种词形。
2. 可以说**コインが入った（コインがはいった）**。你在报告硬币越过边界进入机器。背后有人投入，不妨碍你只描述硬币的变化。
3. 入れる的词干是**ire-**；入れられる在它之后增加られる。检查袋子能否装下东西时，可能表示“能放入”；从球受到了什么处理来讲时，可能表示“被放入”。场景决定当前表达的是能力还是被动。
4. 気に入る（きにいる）是合意、喜欢，东西进入心意接受的范围；入学（にゅうがく）是进入学校；入内（じゅだい）是后妃入宫；一入（ひとしお）是格外、更深一层，可接回布多浸一层、颜色更深的画面。**入魂（じっこん）**记人与人交情深；**入魂（にゅうこん）**记把心力倾注作品。じっ这一形式与字音じゅう的旧音支线相连。

<h2 id="answer-8d77">起｜看见整个家族，o就不再像他动按钮</h2>

1. 起こる含o，却在讲事情发生；因此o不专门表示他动。**起こす的s**能借“促成”来记：把孩子叫醒、引起问题。
2. 可以这样讲：共同的基础接r或s时保留o，接另一母音成分时发生融合，形成了i这一支。于是おき与おこ是同一家里不同接合留下的声音，配对时把它们一起认。
3. **起きられない**谈有没有能力起床；**起こされた**谈受到了别人的叫醒作用。表达今早被弟弟叫醒，可以说**弟に起こされた（おとうとにおこされた）**。先找“起来”还是“叫醒”这个完整动词，再处理可能或被动。
4. 起床（きしょう）开始一天；起点（きてん）开始路程；起動（きどう）开始运行；起業（きぎょう）开始事业。**同一个き，把起来、开始、使事情动起来连成一组。** 起動也让本章的起与下一组要认的動・どう相遇。

<h2 id="answer-843d">落｜使对象掉落，包括无意的失手</h2>

1. **うっかりスマホを落とした**很自然。落とす表达我的行为导致手机掉落；うっかり补上不小心这一层。是否故意与句子是否表达对对象的作用，是不同的信息。
2. 待つ／待ちます可以比较成mat-u／mat-i-masu。共同的t在i前呈现ち，在其他接合中呈现同一行的相应声音。于是**ot-i-ru／ot-os-u**可以把おちる／おとす的ち与と接起来，标准读音仍是おちる／おとす。
3. 老师安排，学生执行松手，球掉下。**落とす**先表达学生使球掉落；**落とさせる**再加上老师让学生做这件事。认清三位参与者，较长的词形就有了对应的信息。
4. 落葉（らくよう）、下落（げらく）保留らく；落下（らっか）在らく与か接合时形成促音，**ら・っ・か**是三拍。叶子离开树枝，价格离开原来的高位，都能借“从原位往下落”记。下落还让下・げ与落・らく在一个词里相遇。

<h2 id="answer-6b62">止｜停住移动，或不再做事</h2>

1. **ボールを止める（ボールをとめる）**，拦停球；**ゲームをやめる**，不再玩游戏。前者看把运动中的对象制止住，后者看主体不再继续某种行为。
2. 止まる表示进入停止状态，ている可以把这次变化后的状态保留下来，于是车停在那里。起きる表示醒来，起きている也可以保留醒着的状态。
3. 控制的是**损失扩大的范围、程度**。とどまる使人想到仍留在某个范围里；とどめる则把对象限制在这个范围内。空间的边界换成程度的边界，关系仍然成立。
4. **よす**接到意志形是よそう，“就算了吧”；接て形是よして，“别再做了”。停止（ていし）让运行停住；中止（ちゅうし）让活动不再进行，或取消原定计划；禁止（きんし）规定某件事不可做。三个字音词都让止读し，具体的停止关系由整个词说出来。

<h2 id="answer-52d5">動｜完整词干决定你在谈哪种动作</h2>

1. 共同部分是**ugok-**，相关他动词增加**as**，成为ugokas-。k和u组成く，和a组成か，所以假名的切口会遮住保持不变的k。认出这层结构，还能去认ter-u／ter-as-u。
2. **動かない**否定动：ugok-a-nai。**動かさない**否定使对象动：ugok-as-a-nai。两边都能出现a；完整的ugok与ugokas才告诉你先选中了哪个动作。
3. 腿疼动不了，**動けない**，判断自身移动的能力。箱子搬不动，**動かせない**，判断使箱子移动的能力。先画出谁动、谁作用于什么，再选可能形式。
4. 運動（うんどう）：身体活动；行動（こうどう）：实际做出行动；感動（かんどう）：内心受到触动；起動（きどう）：机器等开始运行。**活动发生的地方换了，动起来、发生变化的关系还能反复使用。** 每个どう都读长音，ど・う两拍。

<h2 id="answer-958b">開｜同形用法与准备好的结果</h2>

1. 花是自己展开的主体；书是被展开的对象。**ひらく本来就有两种用法**，场景和名词角色会告诉你当前是哪一种。
2. **視界が開けた**中的ひらける是变得开阔；**このファイルは開ける**中的ひらける在这个场景下是ひらく的可能形式，能打开。一个报告发生的变化，一个判断动作的可行性。
3. **窓は開けてある**更贴近“已经预先做好了”的意图。它保留人为安排及其结果。**窓が開いている**适合报告看到的开着状态，两句都能用于那扇已经打开的窗。
4. 開会（かいかい）是会议、集会开始；開店（かいてん）是开店或开始营业；公開（こうかい）是向公众开放、公开。活动开始展开，店门向顾客打开，内容向公众打开。对应的关闭方向是**閉会（へいかい）／閉店（へいてん）**，把かい与へい一起配对记。

<h2 id="answer-7167">照｜把光、作用对象和感受分清</h2>

1. 第二句增加的是**光作用于道路**这一关系。太阳仍是主语，道路成为被照到的对象。ter-as-u里的as可以接到“对对象产生相关作用”的记忆线上。
2. 照る保留ter-，连用形接i成为照り，能表示表面的光泽；焼き来自焼く的连用形。看见酱汁让烤制食物表面发亮，就能把**照り＋焼き**与料理外观接起来。
3. 感到难为情，用**照れる**，借聚光灯落在自己身上的画面记；路被照亮，用**照らされる**，它来自照らす的被动。两种词形分别对应人的感受与道路受到的作用。
4. 照明（しょうめい）、日照（にっしょう）谈光照；参照（さんしょう）、対照（たいしょう）谈参考、比较。**用光照清楚东西，换成把材料摆在一起看清关系。** 相近字形还可带出昭・しょう、招・しょう、召・しょう，例如昭和、招待、召集。

<h2 id="mixed-answers">八个混合场景</h2>

### 01｜先调低，再报告水平

**音量を下げた（おんりょうをさげた）**，我把音量调低了。**音量が下がった（おんりょうがさがった）**，音量降低了。自动词这一句选的是音量的变化，并不承担说明原因的任务。

### 02｜离开的范围与拿出的对象

**部屋を出た（へやをでた）**，我出了房间。**ポケットから鍵を出した（ポケットからかぎをだした）**，我从口袋拿出了钥匙。前句的を标出离开的房间，后句的を标出被拿出的钥匙。相同助词在两个事件中连接不同角色。

### 03｜硬币进去了

**コインが入った（コインがはいった）**。改成我的投入动作，可以说**コインを一枚入れた（コインをいちまいいれた）**。从硬币的去向换到对硬币的动作，入る换为入れる，硬币从が前的主体换到を前的对象。

### 04｜被声音吵醒

**外の物音で起こされた（そとのものおとでおこされた）**。起こされた来自叫醒的起こす，表达受到声音的作用。起きた只报告起来；起きられる判断起床能力。三个词形增加的信息不同。

### 05｜我的失手与手机的掉落

**うっかりスマホを落とした**，我不小心把手机弄掉了。**スマホが落ちた**，手机掉了。前句把我导致手机掉落的关系说出来，后句沿手机的变化说。うっかり已经把无意失手的信息补足。

### 06｜我能动，却挪不动它

**自由に動ける（じゆうにうごける）**，能自由活动。**この箱は重くて動かせない（このはこはおもくてうごかせない）**，箱子太重，挪不动。前者在動く上谈可能，后者在動かす上谈可能并加否定。

### 07｜已经开好窗了

**窓はもう開けてある（まどはもうあけてある）**，窗已经开好了。它最能接住“为客人通风的准备已完成”。若只是看了一眼报告状态，则可说**窓が開いている（まどがあいている）**。

### 08｜老师让学生去做

**先生が生徒にボールを落とさせた**。老师安排学生执行使球掉落的动作，所以在落とす上加使役。单说**ボールが落ちた（ボールがおちた）**，只报告球的掉落，没有表达老师安排学生行动这层关系。
